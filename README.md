# NEXORA

A premium, dark-glassmorphism social networking web app UI built with plain HTML, CSS and JavaScript (no build step, no dependencies).

## Screens
Landing, Login, Sign Up, Home Feed, Profile, Explore, Friends, Messages, Notifications, Settings.

## Features
- Responsive 3-column desktop layout, tablet icon rail, mobile bottom navigation
- Stories, create-post card, like/save animations, comment previews
- Chat with typing indicator, read receipts and send
- Live notification badge and toast
- Dark/light theme, keyboard focus styles, reduced-motion support

## Run locally
Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy to GitHub Pages
1. Push this folder to a GitHub repo.
2. Settings > Pages > Deploy from branch > `main` / root.

## Structure
